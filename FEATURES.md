# Windows feature coverage

RustyFin targets Jellyfin on Windows. This comparison uses the [Plezy feature list at revision 8310991](https://github.com/edde746/plezy/blob/8310991fa14f0cbac9c71cfb494d028d4314c7ff/README.md#features). It tracks the user-visible behavior of RustyFin’s two playback engines.

| Area | Available in RustyFin | Remaining work |
| --- | --- | --- |
| Browse | Discover shelves, featured carousel, resume, Up Next, collections, playlists, folders, extras, cast and crew, ratings, sorting, letter navigation, favorites and unwatched filters. Play or shuffle a whole library, folder, series, album or playlist. | More recommendation sources and spotlight layout options. |
| Multiple servers | Quick Connect or username and password sign-in, local server discovery, saved accounts, profile switching, federated search for titles and people, and a copy picker for matching Continue Watching entries. Enable **Search all servers** in Settings. | Several alternative addresses for a single server. |
| Video | Original-file playback, per-version file and stream info, remembered audio and subtitle choices, resume, chapter jumps, chapter-image scrub previews, intro and credit markers, episode queues, autoplay, sleep timers and opt-in fullscreen refresh-rate matching. mpv supports speed, audio offset, zoom, styled ASS/SSA captions, outline presets and live shader switching with built-in presets and local shader files. | Pinch zoom and ambient lighting. |
| Native Dolby Vision | Windows Media Foundation, Dolby Extensions, DirectComposition, local audio decoding, supported digital bitstreams and automatic Profile 7 MEL to 8.1 and FEL to HDR10 playback for single-track HEVC remuxes. Text subtitles use a synchronized caption area below the picture. | Bitmap subtitles, styled ASS overlays and dual-track Profile 7 and full enhancement layer reconstruction. |
| Audio | Automatic WASAPI passthrough or local PCM on compatible outputs. Passthrough can be switched off per profile. mpv PCM playback supports stereo or 5.1 limits, center-channel boost in stereo downmixes and loudness normalization. | Equivalent PCM controls on the native Windows engine. |
| Music | Artist, album and track browsing, square artwork, play, shuffle, Instant Mix, a reorderable queue, play next, synced lyrics, persistent mini-player, offline tracks and albums, Windows media transport controls. | Gapless transitions. |
| TV and DVR | Channels and favorites across enabled servers, current program, channel schedules, single and series recordings, rule listings and cancellation. Direct-play live tuners are opened and released through Jellyfin. | Aggregating scheduled recordings across servers. Actual channels and recording capabilities depend on the server and tuner. |
| Downloads | Original-file downloads with pause, range resume, offline playback, watch-state sync, cached cover art and lyrics, offline album and series queues, batch downloads and per-show unwatched-episode rules with optional specials. | Automatic eviction of played episodes. |
| Explore and services | Seerr trending, popular titles, catalog search, exact external-ID matching, movie and per-season requests, 4K, destination, quality profile and root folder. AniList trending, popular titles, search, watchlist, ratings, progress and opt-in completion sync for matching anime. Optional MDBList ratings and Discord Rich Presence. | Trakt, MyAnimeList and Simkl catalogs, watchlists, ratings and scrobbling. Additional recommendation sources. |
| Shared playback | Local playback queues and Windows media commands. | Open Watch Party rooms, relay selection, shared playback control and host handoff. |
| Windows controls | Per-display Windows HDR status and controls, fullscreen, keyboard navigation, remappable playback shortcuts, XInput controller navigation, Windows media keys, desktop media session, settings import and export. | Plezy Remote compatibility, deep links, additional TV layouts and translations. |
| Library editing | Find and download subtitles through Jellyfin’s configured providers. Administrators can edit a title and overview and replace its poster, backdrop or logo. | More metadata fields and a remote artwork picker. |

The requested playback policy is original quality. Jellyfin transcode presets, including lower-bitrate music streams, fall outside that policy. Plex- and Emby-specific account behavior and mobile-only features fall outside the Windows Jellyfin target.

## Verification

The Windows fixture uses an actual GPUI window, libmpv and a local HTTP server. It exercises track selection and switching, playback controls, download interruption and resume, offline playback, progress sync, music, lyrics, Windows media-session creation, Seerr requests, MDBList rating lookup, subtitle-provider download, AniList list updates, metadata editing and Jellyfin tuner and DVR requests. It uses temporary account data. A simulated tuner or request service verifies the client’s requests and state handling. Refresh-rate selection has a cadence test. Physical mode switching is opt-in. Validation against a physical tuner, a configured production Seerr account, a Discord desktop account, a controller and an HDMI audio receiver is separate.

The native Profile 5 sample produced decoded and rendered frames on the PG32UCDMR when Windows reported its Dolby-compatible output mode. A later native subtitle run encountered an SDR output report on that same monitor. End-to-end presentation of native captions on that display remains unverified. The caption cue parser and the display-mode decision have independent tests.
